发票二维码识别下载工具 · 使用说明
================================

【功能】
1. 识别指定文件夹内图片中的二维码。
2. 二维码为网址：自动下载对应 PDF 到「PDF」子文件夹，文件名与原始图片相同。
3. 二维码为纯数字：忽略，不做任何处理。
4. 未识别到二维码 / 二维码无法识别：图片重命名为「未识别-原文件名」。
5. 二维码为网址但无可下载的 PDF：图片重命名为「未下载原文件名」。
6. 同一网址在多处出现（重复）：对应图片文件名前加「重复」。
7. 成功识别并下载到 PDF 的图片：文件名前加「1」，标记该图片已完成下载。
8. 可选：处理完成后自动打开文件夹。
9. 可选：将下载的 PDF 转为图片（长边 2000px，短边自适应），保存到「PDF/图片」。
10. 可选：处理完成后汇总发票（生成 Excel）。对「PDF」文件夹内所有发票 PDF，
   提取「交款人 / 票据号码 / 开票日期 / 金额合计（小写）/ 医保统筹基金支付」，
   汇总为「PDF/发票汇总_YYYYMMDD_HHMMSS.xlsx」，并带合计行（金额、医保统筹自动求和）。
11. 处理结束后弹出「识别结果统计」：分项统计总计识别图片、成功下载 PDF、识别但未下载、
   纯数字忽略、识别失败各多少张，重复网址另计。

【使用步骤】
1. 把待处理的图片放在同一个文件夹里。
2. 打开本软件，点「浏览…」选择该文件夹。
3. 按需勾选：
   - 处理完成后打开文件夹
   - 将下载的 PDF 转换为图片（长边 2000px）
   - 处理完成后汇总发票（生成 Excel）
4. 点「开始处理」，在日志区查看进度。
5. 处理完成后，PDF 在「PDF」文件夹，转换图片在「PDF/图片」，汇总表在「PDF/发票汇总_*.xlsx」。

【自动更新】
- 软件启动后会静默检查 GitHub 上的最新版本；发现新版本时弹窗提示，点「是」即自动
  下载并替换当前程序（无需手动去网页下载）。
- 也可随时点主界面「检查更新」按钮手动检查。
- 更新源为公开仓库 jianRY/invoice-qr-tool 的 Release，全程无需账号或令牌。

【输出规则速查】
- 网址 + 下载成功      → PDF/<原名>.pdf，且原图片改名「1<原名>」标记已完成
- 网址 + 无 PDF 可下载 → 图片改名「未下载<原名>」
- 纯数字二维码         → 忽略
- 无/无法识别二维码     → 图片改名「未识别-<原名>」
- 重复网址             → 图片加「重复」前缀
- 上述情况可叠加，例如「未下载重复<原名>」「重复1<原名>」
- 勾选汇总             → PDF/发票汇总_YYYYMMDD_HHMMSS.xlsx（含合计行）

【汇总字段说明】
针对江苏省医疗门诊收费票据 / 电子票据模板：
- 交款人、票据号码、开票日期、金额合计（小写）、医保统筹基金支付。
- 不支持的票据模板可能无法正确提取，相关单元格会留空或标记「解析失败」。

【说明】
- 二维码识别使用 zxing-cpp，对截图 / 小二维码会自动多尺度放大，比 OpenCV 自带更稳。
- 部分发票平台（如 jsczt.cn）打开后是一个展示页，软件会自动提取页面隐藏参数并提交下载接口获取 PDF。
- 单文件 EXE，无需安装，双击即用。
- 软件内也内置「使用说明」窗口（点界面右上角「使用说明」按钮即可查看）。

【自动更新与回滚】
- 软件启动后会静默检查 GitHub 上的最新版本；发现新版本时弹窗提示，点「是」即自动
  下载并替换当前程序（也可点「检查更新」按钮手动触发）。更新全程无需账号或令牌。
- 更新过程会弹出「更新进度」提示框，实时展示：更新阶段、进度条、下载速度（MB/s / KB/s）、
  已下载大小与详细日志；下载完成后自动替换并重启，无需手动干预。
- 更新失败会自动回滚：替换前会备份当前程序；新版本若启动校验失败，会自动还原回旧版本
  并重新打开，并弹出「更新已回滚」提示框告知你已还原到可用版本，不会把软件弄坏、也不静默。
- 启动速度已优化：重型依赖（OpenCV / PyMuPDF / pdfplumber / openpyxl 等）改为用到时才加载，
  软件打开更快。
